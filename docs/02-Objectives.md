# 02. Project Objectives

## Primary Objectives
1. **Automate Technical Skill Matching**: Implement a rule-based matching algorithm to calculate exact percentage compatibility between task requirements and developer profiles.
2. **Centralize Developer Resource Profiles**: Maintain verified directories of software engineers, including their departmental roles, industry experience, and technical skill proficiencies.
3. **Streamline Task Allocation Lifecycle**: Enable resource managers to create tasks, attach skill criteria, review ranked recommendations, and allocate developers with one click.
4. **Empower Developer Self-Service**: Provide dedicated developer dashboards where engineers can view assigned tasks and update work status (`To Do` → `In Progress` → `Completed`) in real time.
5. **Deliver an Enterprise-Grade SaaS Interface**: Provide a modern corporate SaaS UI with clean typography (Inter font), responsive layout, and synchronized Light/Dark theme switching.

## Software Engineering Pedagogical Goals
- Demonstrate clean 3-tier MERN (MongoDB, Express, React, Node.js) web architecture.
- Model realistic relational data structures using Mongoose ObjectIds and population queries.
- Implement robust role-based authorization (Admin vs. Developer) using stateless JSON Web Tokens.
